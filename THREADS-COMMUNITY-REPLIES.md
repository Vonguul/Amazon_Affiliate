## House rule: same 9:1 discipline as Reddit and X

Same process as `REDDIT-POSTS.md` and `X-COMMUNITY-REPLIES.md`: search for
genuine, recent conversations; reply helpfully first; a link goes in only
when it's a real match for what was actually asked or said. Never canned
copy, never a link dropped just because a thread is topically adjacent.
Threads get skipped, not forced, when nothing in Picks/Clarity fits.

Because this is the user's real identity (not a persona account like
Reddit's), the bar for a link is higher, not lower — a spammy reply here
lands on the user's own name.

## Gotchas (found 2026-09-29)

- **Verify composer focus before typing.** `document.activeElement` should
  be the contenteditable labelled "Empty text field. Type to compose a new
  post." — same class of problem as X's reply box.
- **Frozen tabs** after several posts: close the tab and open the thread
  URL fresh rather than retrying clicks on a stuck renderer.
- **"Posting..." lingers for several seconds** after hitting send; wait and
  re-read the page before assuming it failed (don't resend — that
  double-posts).
- Threads replies have ~500 chars, so a genuine tip + link fits in one
  reply; no need for X-style reply chains.
